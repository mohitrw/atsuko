Atsuko User Manual

🎵 Offline Library

Add folders or local audio files using the + button on the sidebar. Atsuko scans and parses metadata completely offline.

⌨️ Keyboard Navigation

• A / D — Switch view modes in PC view (Songs List, Lyrics, 3-Column Grid, and Up Next).
• S — Toggle playback mode between Shuffle, Repeat On, and Repeat Off.
• Space — Play or Pause playback.
• N — Skip to the Next song.
• P — Play the Previous song.
• L — Enter Full View mode (covers the full screen displaying only the current playing song with large artwork and interactive lyrics).
• ← / → — Seek 5 seconds backward or forward.

🎙️ Voice Recorder

Record notes and live audio in the Library → Recorder section. Files can be stored directly on your PC disk.

🎨 Themes & Sound

Toggle between Dark and Light mode from the Settings popup. Enjoy lossless offline playback and acoustics.
